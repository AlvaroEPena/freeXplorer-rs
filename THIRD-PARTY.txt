WinFsp
------
WinFsp - Windows File System Proxy, Copyright (C) Bill Zissimopoulos
https://github.com/winfsp/winfsp

Mounting on Windows goes through WinFsp, a file system driver that is installed
separately. It isn't included. The program loads winfsp-x64.dll from wherever WinFsp is
installed when you mount something.

winfsp-rs
---------
The winfsp and winfsp-sys crates (https://github.com/SnowflakePowered/winfsp-rs), which
are the Rust bindings to WinFsp, are licensed under GPL-3.0. That is why this program is.
